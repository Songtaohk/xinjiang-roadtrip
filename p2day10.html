Day 10 · 8月25日（周二）

布尔津 → 贾登峪（轻松日 / 全程唯一的机动缓冲日）

全程最轻松的一天：上午从布尔津北上进入阿尔泰山腹地，中午抵达贾登峪，下午自由休整。当晚住贾登峪是为了用掉那张改期的酒店订单；同时这也是整个方案2里唯一可以随时砍掉、用来补回一天的机动日

🚗交通

路线布尔津 → 贾登峪（S232/县道，山区公路）
里程约150公里（参考已核实的贾登峪→五彩滩147公里，两地基本同一路线）
车程纯驾车约3小时（布尔津→贾登峪）。⚠️注意区分：这3小时只算到贾登峪停车场为止。如果按备选走法当天就要换乘进喀纳斯湖区，还要再加上停车、安检、排队买/验票、景区区间车、以及到湖区后办理住宿登记，这一串加起来通常还要1.5-2小时，门到门应按4.5-5小时预留
海拔变化布尔津 ~480m → 贾登峪 ~1350m（爬升约870m）
历史天气参考布尔津日间较热，贾登峪因海拔高明显凉爽，日间约18-23℃、夜间5-9℃
加油站布尔津县城加满油；贾登峪有喀纳斯加油站（0906-6327566，09:00-23:00，来自"原行网"官方公众号名单）
是否需预约今天不进景区，无需门票。⚠️但今天要把明天的喀纳斯门票买好：方案2的喀纳斯只跨8/26-8/27两个自然日，理论上「一进票」（有效期2天）即可覆盖，不再像方案1那样必须买「二进票」（有效期3天）——但购票前请用实际入园/出园日期再核对一次有效期规则，以景区当日公告为准。
驾车注意事项：🎯这一天是方案2唯一的"机动缓冲日"，请先读这一段：整个方案2里，只有今天可以随时砍掉而不影响其他任何安排。砍掉的方式很简单——今天不在贾登峪过夜，而是直接布尔津 → 贾登峪 → 换乘 → 当晚住喀纳斯湖区（门到门约4.5-5小时，下午两点多就能安顿好，详见下方的备选时间预算），后面所有天顺次提前一天，行程末尾空出一整天。

📋到时候照这张表决定就行，不用现场纠结：
• 前面没耽搁 ＋ 贾登峪改期成功 → 住贾登峪，今天当休整日，用掉那张不可取消的房。这是默认情况。
• 前面没耽搁 ＋ 改期失败 → 直接进喀纳斯。那张房反正已经作废，留在贾登峪没有意义，省下1天。
• 前面有耽搁（如夏塔闭园顺延）＋ 改期成功 → 直接进喀纳斯，房钱认了，用这1天把进度追回来。
• 前面有耽搁 ＋ 改期失败 → 直接进喀纳斯，省下1天。
👉 一句话：只有"没耽搁且改期成功"这一种情况才住贾登峪，其余三种都直接推进喀纳斯。

还有什么时候该拉这个杠杆：①前面任何一段因封路/堵车/车辆故障丢了时间；②你临时想给赛里木湖或喀纳斯多加一晚。
为什么砍这一天比压缩别的天更好：D9如果硬接着开到贾登峪，全天会变成630公里/11小时以上，还要牺牲五彩滩日落；而砍掉今天，没有任何一天车程超过5小时，五彩滩日落也保住了。

💡为什么默认保留这一天：单纯从行程效率看，今天完全可以直接从布尔津开到贾登峪再换乘进喀纳斯，当晚就住湖区，把贾登峪这一晚省下来。之所以特意在贾登峪留一晚，是为了给8月18日那张不可取消的喀纳斯童话故事国际酒店订单留出改期使用的位置（详见首页的"预约与改期总览"）。代价是喀纳斯从方案1的连住2晚压缩为1晚。⚠️如果商家不同意改期，那么这一晚就失去了意义，建议改回"今天直接换乘进喀纳斯住湖区、明天全天游、后天一早看晨雾再走"的安排，等于喀纳斯恢复2晚——这样反而更好，只是那张8/18的房费就彻底作废了。所以务必先联系飞猪商家确认能否改期，再决定今天怎么走。⚠️贾登峪停车信息：这一带有多个免费停车场（太阳城堡、演艺中心150车位、风情园100车位、大森林、餐饮广场100车位，以及各酒店自带约550车位），30分钟内临时停车普遍不收费，超时收费标准不完全统一，建议入住时直接向酒店确认能否连续停车、是否收费——因为明天开始车要在贾登峪停两天两夜。⏰建议时间预算——主方案（改期成功，当晚住贾登峪）：8:00早餐，8:30从布尔津出发（不要拖到9点半以后，山区路况和排队都有不确定性），3小时车程，11:30-12:00抵达贾登峪办理入住，午餐12:30-13:30，下午自由休整（这一天刻意留白，因为前面D8/D9连续两天长途转场需要缓一缓，也为接下来喀纳斯/禾木的连续早起攒精力），18:00-19:00晚餐，19:00后可在贾登峪散步看晚霞（这一带纬度高，日落后天还亮很久）。⏰建议时间预算——备选（改期失败，当天直接进喀纳斯湖区）：这种情况下今天会变成一个实打实的半长途日，务必8:00前后就从布尔津出发：8:00出发 → 11:00到贾登峪 → 停车、寄存大件行李、安检验票、排队等区间车约1-1.5小时 → 12:30前后坐上区间车 → 约1小时车程 → 13:30-14:00抵达喀纳斯换乘中心 → 办理湖区住宿登记约30分钟 → 14:30前后安顿完毕。门到门共约4.5-5小时，下午进村即可，当天不要再额外插入景点，把三湾和观鱼台完整留到明天。

📍活动安排

贾登峪国家森林公园（自由休整）
游览时间：视精力而定
贾登峪本身是国家森林公园，山间盆地地形，四周森林环抱，也是喀纳斯、禾木、白哈巴三大景区的统一售票换乘枢纽。
园区内有毡房群、山丘森林和欧式城堡风格建筑；这一天刻意不排满，把它当作前面两天长途转场后的缓冲日
购票 + 车辆安置准备
游览时间：约1小时
接下来两晚分别住在喀纳斯湖区和禾木村内，车都停在贾登峪不动，行李分装是必要的准备。
买好明天的喀纳斯门票；向酒店确认车辆可以连续停放两天两夜（明天进湖区、后天中午才回来取车）；整理行李，把进湖区要用的东西单独打包，大件行李寄存在贾登峪
五彩滩补看（可选）
游览时间：约1.5小时
额尔齐斯河北岸的彩色雅丹台地，早晚光线差异很大，两天分别去看会是完全不同的效果。
如果昨天在五彩滩没拍尽兴，今天上午出发前可以再去一次（布尔津县城到五彩滩很近），代价是抵达贾登峪的时间推迟约2小时，但今天本来就宽松
